How to read the graphs

The surface view shows z = xy for −2 ≤ x ≤ 2 and −3 ≤ y ≤ 3. Its teal curve is (x, y, xy) with 4x² + y² = 8. Its orange curve shows points with xy = c at height z = c.

The plane view shows the ellipse and xy = c directly in the xy-plane. For nonzero c, this level set is a hyperbola; when c = 0, it is the two coordinate axes. The plane view uses equal axis scales. The 3D view uses a compressed vertical scale for readability.
